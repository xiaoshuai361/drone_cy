================================================================================
PART 0: 项目概述
================================================================================

本项目是一套基于 PX4 SITL + ROS Noetic + Gazebo 11 的四旋翼无人机仿真系统,
功能包括:
  - PX4 飞控软件在环仿真 (SITL, iris 四旋翼模型)
  - Gazebo 11 温室/森林场景仿真
  - FAST-LIO2 激光 SLAM 建图 (Livox Mid360 仿真)
  - OctoMap 三维地图 + 2D 栅格地图
  - MAVROS 飞控通信
  - 多种路径规划: A* 全局覆盖、RRT* 3D 避障、弓字形覆盖
  - 动态障碍物避障 + 自动重规划
  - C++ 和 Python 双版本实现

所有代码均已上传 GitHub, 香橙派上全程通过 git clone 获取, 无需 U 盘.

PART 3: ~/.bashrc 配置 (完整内容)
================================================================================

在 ~/.bashrc 末尾应添加以下内容 (orangepi_setup.sh 第12步自动写入):

  source /opt/ros/noetic/setup.bash
  source ~/catkin_ws/devel/setup.bash
  export PATH=$HOME/.local/bin:$PATH
  export PX4_HOME=$HOME/PX4-Autopilot

  setup_px4_env() {
    source $PX4_HOME/Tools/simulation/gazebo-classic/setup_gazebo.bash \
      $PX4_HOME $PX4_HOME/build/px4_sitl_default 2>/dev/null
    export ROS_PACKAGE_PATH=$ROS_PACKAGE_PATH:$PX4_HOME:$PX4_HOME/Tools/simulation/gazebo-classic/sitl_gazebo-classic
  }

  setup_px4_env

  alias use_cpp='source ~/catkin_ws_cpp/devel/setup.bash && setup_px4_env && echo "[OK] C++工作空间 + PX4 已加载"'
  alias use_py='source ~/catkin_ws/devel/setup.bash && setup_px4_env && echo "[OK] Python工作空间 + PX4 已加载"'

使用说明:
  - 默认加载 Python 工作空间
  - 切换 C++ 工作空间: 执行 use_cpp
  - 切换回 Python 工作空间: 执行 use_py

PART 7: ⚠️ 重要注意事项 (GPU Ray 问题)
================================================================================

问题描述:
  仿真使用 GPU Ray 插件模拟 Mid360 LiDAR:
    sensor type="gpu_ray"  +  libgazebo_ros_velodyne_gpu_laser.so

  Orange Pi 5 Pro 的 Mali-G610 GPU 不支持 CUDA,
  Gazebo gpu_ray 需要 OpenGL GPU 加速.

解决方案 (推荐): 改用 CPU Ray 插件
  修改文件:
    ~/catkin_ws/src/mak4_sim/models/iris_rgbd_lidar/   (找到对应 SDF/URDF)
  将:
    type="gpu_ray"                           → type="ray"
    libgazebo_ros_velodyne_gpu_laser.so      → libgazebo_ros_velodyne_laser.so
  可选: 降低点数 (samples 360 → 180) 减轻 CPU 负担

PART 10: 常见错误排查
================================================================================

1. catkin_make 内存不足 (OOM Killed):
   → catkin_make -j1
   → 增加 swap:
       sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile
       sudo mkswap /swapfile && sudo swapon /swapfile
       echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

2. PX4 编译报 "No module named 'jinja2'" 或 empy 相关错误:
   → pip3 install --user jinja2 "empy==3.3.4" pyserial
   → 重新运行 make

3. Gazebo 无法启动 / 黑屏:
   → 强制软件渲染: export LIBGL_ALWAYS_SOFTWARE=1
   → 安装 Mesa: sudo apt install mesa-utils libgles2-mesa-dev

4. FAST_LIO 编译报 Eigen 或 PCL 错误:
   → sudo apt install libeigen3-dev libpcl-dev

5. MAVROS 报 "url scheme not supported" (url_scheme):
   → GeographicLib 数据集缺失, 见 PART 9

6. roslaunch 找不到包:
   → source ~/.bashrc
   → 手动: source ~/catkin_ws/devel/setup.bash && setup_px4_env

7. PX4 git submodule 超时/失败:
   → 在有 GitHub 访问的机器上完整 clone PX4, 打包 .git 子模块后复制
   → 或使用代理: git config --global https.proxy http://proxy:port
