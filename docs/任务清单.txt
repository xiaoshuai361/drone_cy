核心方案一：FAST-LIO2（快速激光惯性里程计）+ Z轴直通滤波（业内绝对主流，强烈推荐！）
这是目前香港大学（HKU）开源的全球最火、速度最快、鲁棒性最强的 3D 激光雷达建图算法。
第一步（建大地图）： 运行 FAST-LIO2 跑一遍仿真大棚。与 OctoMap 疯狂做概率数学运算不同，FAST-LIO2 直接提取激光的点、面特征进行位姿估计，并拼接出全局高精度的 .pcd 点云图。建几公里的大地图几乎不费吹灰之力，绝不会卡死。
第二步（提取导航平面）： 假设你的定高飞行高度是 z=1.0
在获取的 3D PCD 全局地图后，使用 PCL (Point Cloud Library) 的直通滤波器（PassThrough Filter），把 Z 坐标在 
0.8 米 到 1.2 米 之间的点云切片单独拿出来。
第三步（生成规划地图）： 将切片下来的点云压平（Z轴设为0），投影生成一张标准的黑白 2D 占据栅格地图（.pgm 格式，ROS 中的 map_server 格式）。
导航路径： 有了这张 2D 栅格地图，你就可以使用全局 A* 或 Dijkstra 算法规划航线，无人机定高起飞后顺着航线飞，完美避开该高度区间的藤蔓和铁丝。

任务21 补充 — 修复 EKF2 参数 GET 报错
问题: 启动大棚/森林仿真时控制台出现:
  PR: Unknown parameter to get: EKF2_HGT_REF
  PR: Unknown parameter to get: EKF2_HGT_MODE
  PR: Unknown parameter to get: EKF2_BARO_NOISE
原因: configure_ekf2 的 wait_for_params_ready() 用上述三个 EKF2 参数探测 PX4 参数系统是否就绪,
      但这些参数在 PX4 v1.14.3 中不一定存在, MAVROS 的 GET 服务会报错。
修复: 将探测参数改为 MAV_SYS_ID (所有 PX4 版本都存在)
涉及文件:
  - Python: ~/catkin_ws/src/mak4_sim/scripts/configure_ekf2.py
  - C++:    ~/catkin_ws_cpp/src/mak4_sim_cpp/src/configure_ekf2_node.cpp
