================================================================================
第一阶段: 飞控基础验证 (不装机载电脑, 仅RC遥控器)
================================================================================

目的: 确认飞控固件、传感器、电调、电机正常工作

步骤 1.1 — 地面检查 (不通电桨叶)
  □ 拆除或不安装螺旋桨 (安全第一!)
  □ 连接电池, 听飞控蜂鸣器初始化音
  □ 用 QGroundControl (QGC) 连接飞控:
    - USB数据线直连, 或 WiFi/数传
  □ QGC中检查:
    - 固件版本: PX4 v1.14.3
    - 传感器校准: 加速度计、陀螺仪、磁力计 (已校准则绿色勾)
    - RC校准: 确认遥控器所有通道响应正确
    - 电调校准: 确认4个电机方向正确 (QGC电机测试页面)
    - 安全开关: 设置好故障保护 (RC丢失→自动降落, 低电量→RTL)

步骤 1.2 — 手动飞行测试 (室外空旷场地)
  □ 安装螺旋桨
  □ 切换到 Position 模式 (遥控器模式开关)
  □ 解锁并起飞到约 1.5m
  □ 验证:
    - 悬停稳定性 (不飘移)
    - 四个方向平移响应
    - 偏航旋转
    - 上升/下降
  □ 降落, 确认一切正常

步骤 1.3 — 室内光流+测距仪验证
  □ 在室内平坦地面 (有纹理, 光照充足)
  □ QGC中确认:
    - EKF2_HGT_REF = 2 (测距仪定高) — 或 EKF2_HGT_MODE = 2
    - EKF2_RNG_CTRL = 2 (始终用测距仪) — 或 EKF2_RNG_AID = 2
    - EKF2_OF_CTRL = 1 (启用光流)
    - EKF2_RNG_A_HMAX = 8.0 (测距仪最大有效高度)
  □ Position模式起飞, 松杆悬停
  □ 验证:
    - 高度稳定 (不用GPS, 仅靠测距仪)
    - 位置稳定 (不用GPS, 仅靠光流)
    - 如果漂移严重 → 检查光流安装方向、地面纹理、光照

第二阶段: 机载电脑通信验证 (先不飞, 地面测试)
================================================================================

目的: 确认机载电脑能通过 MAVROS 与飞控正常通信

步骤 2.1 — 机载电脑环境搭建
  □ 安装 Ubuntu 20.04 + ROS Noetic (参考仿真环境)
  □ 安装 MAVROS:
    sudo apt install ros-noetic-mavros ros-noetic-mavros-extras
    # 安装 GeographicLib 数据集:
    sudo /opt/ros/noetic/lib/mavros/install_geographiclib_datasets.sh
  □ 安装 Fast-LIO2:
    cd ~/catkin_ws/src
    git clone https://github.com/hku-mars/FAST_LIO.git
    # (按照仿真环境中的编译方式)
  □ 安装 livox_ros_driver (如果用 Mid360):
    cd ~/catkin_ws/src
    git clone https://github.com/Livox-SDK/livox_ros_driver.git
    cd ~/catkin_ws && catkin_make
  □ 复制 mak4_sim 功能包到机载电脑 (去掉仿真相关的 Gazebo world/model):
    scp -r ~/catkin_ws/src/mak4_sim user@onboard_ip:~/catkin_ws/src/

步骤 2.2 — 串口连接飞控
  □ 飞控 TELEM2 端口 → 机载电脑 USB (通过 FTDI 或直接串口)
  □ 设置波特率 (QGC中 MAV_1_CONFIG = TELEM2, MAV_1_RATE = 921600)
  □ 确认设备节点:
    ls /dev/ttyUSB*    # 应该看到 /dev/ttyUSB0
    # 或 /dev/ttyACM0 (USB直连)
  □ 测试 MAVROS 连接 (不飞, 仅通信):
    roslaunch mavros px4.launch fcu_url:=/dev/ttyUSB0:921600
  □ 验证话题:
    rostopic echo /mavros/state         # connected: True
    rostopic echo /mavros/imu/data      # IMU数据流
    rostopic echo /mavros/local_position/pose  # 位置数据

步骤 2.3 — 激光雷达驱动验证
  □ 连接 Mid360 (以太网/USB)
  □ 修改 livox_ros_driver 配置文件, 设置雷达IP
  □ 启动雷达:
    roslaunch livox_ros_driver livox_lidar_msg.launch
  □ 验证:
    rostopic hz /livox/lidar  # 应约 10Hz
    # 或查看点云:
    rviz (添加 PointCloud2, topic=/livox/lidar)

步骤 2.4 — 深度相机驱动验证
  □ 连接相机 (USB3.0)
  □ 安装驱动 (以RealSense为例):
    sudo apt install ros-noetic-realsense2-camera
  □ 启动:
    roslaunch realsense2_camera rs_camera.launch
  □ 验证:
    rostopic hz /camera/color/image_raw   # 应约 30Hz
    rostopic hz /camera/depth/image_rect_raw

第三阶段: 创建真实飞行Launch文件
================================================================================

目的: 基于仿真的launch文件, 改造为真实飞行版本

步骤 3.1 — 创建 mak4_real.launch (替代 mak4_greenhouse.launch)
  核心区别:
  - 去掉 PX4 SITL + Gazebo (真实飞行不需要仿真)
  - MAVROS 的 fcu_url 改为串口: /dev/ttyUSB0:921600
  - EKF2 参数可能已在QGC中设置好, 不一定需要 configure_ekf2 节点
  - 添加真实的 livox_ros_driver 启动

  参考模板:
  ```xml
  <launch>
      <!-- MAVROS 连接真实飞控 -->
      <node pkg="mavros" type="mavros_node" name="mavros" output="screen">
          <param name="fcu_url" value="/dev/ttyUSB0:921600"/>
          <param name="gcs_url" value=""/>
          <param name="target_system_id" value="1"/>
          <rosparam command="load" file="$(find mavros)/launch/px4_pluginlists.yaml"/>
          <rosparam command="load" file="$(find mavros)/launch/px4_config.yaml"/>
      </node>

      <!-- Livox Mid360 激光雷达 -->
      <include file="$(find livox_ros_driver)/launch/livox_lidar_msg.launch"/>

      <!-- 深度相机 (以RealSense为例) -->
      <include file="$(find realsense2_camera)/launch/rs_camera.launch">
          <arg name="depth_width" value="320"/>
          <arg name="depth_height" value="240"/>
          <arg name="depth_fps" value="10"/>
      </include>

      <!-- 相机TF: body → camera_link -->
      <node pkg="tf2_ros" type="static_transform_publisher" name="body_to_camera_link"
            args="0.12 0 0 0 0 0 body camera_link"/>
  </launch>
  ```

步骤 3.2 — slam_mapping.launch 基本不需要改
  Fast-LIO2 配置文件需要调整:
  - lid_topic: 改为真实雷达话题 (如 /livox/lidar)
  - imu_topic: 保持 /mavros/imu/data
  - 外参 extrinsic_T: 根据真实安装位置测量调整

步骤 3.3 — navigation.launch / navigation_2d.launch 不需要改
  这些已经是纯ROS节点, 不依赖仿真

第五阶段: 首次自主飞行 (简单悬停 + 定点)
================================================================================

⚠ 安全注意事项:
  - 场地足够大, 至少 5m×5m 空旷区域
  - RC遥控器在手, 随时准备切 Position/Manual 模式
  - 先从低高度 (0.5m) 开始
  - 有人在旁边观察, 异常立即切手动
  - 电池电量充足 (>70%)

步骤 5.1 — OFFBOARD模式起飞测试
  □ 启动所有节点:
    终端1: roslaunch mak4_sim mak4_real.launch
    终端2: rosrun mak4_sim keyboard_teleop.py
  □ RC遥控器切到 Position 模式
  □ keyboard_teleop 中按 T 起飞
    - 程序会发送 OFFBOARD 命令, 然后解锁起飞
    - 如果遥控器不在 OFFBOARD 模式开关位, PX4会拒绝
    - ⚠ 建议: 先用遥控器手动起飞到 1m, 然后切 OFFBOARD 开关
  □ 观察:
    - 起飞到 1.5m 后是否稳定悬停
    - 高度是否锁定 (测距仪+光流)
  □ 按 W/S/A/D 测试前后左右移动
  □ 按 L 降落

步骤 5.2 — 速度调整
  □ 真实飞行中速度应该比仿真低!
  □ 建议初始速度:
    - linear_speed: 0.3 m/s (仿真中用了0.5)
    - vertical_speed: 0.2 m/s (仿真中用了0.3)
  □ 确认稳定后再逐步提高

================================================================================
故障排除
================================================================================

Q: MAVROS连不上飞控
A: 检查串口设备权限: sudo chmod 666 /dev/ttyUSB0
   检查波特率是否匹配 (QGC中 MAV_1_RATE)
   检查数据线是否是数据线 (非充电线)

Q: 起飞后疯狂漂移
A: 光流传感器安装方向可能反了
   地面纹理不足 (铺报纸/地毯)
   光照不足 (补光)

Q: 高度不稳定
A: 测距仪安装不正 (必须垂直朝下)
   地面不平坦或有障碍物干扰
   检查 EKF2_HGT_REF 是否设为 2 (测距仪)

Q: OFFBOARD模式飞控拒绝
A: RC遥控器需要有 OFFBOARD 通道开关
   先手飞起来, 再切 OFFBOARD
   setpoint 必须先发送 2 秒以上才能切 OFFBOARD

Q: Fast-LIO2 建图漂移
A: IMU校准不良 → 重新校准
   雷达外参不准 → 测量并修改 extrinsic_T
   运动太快 → 放慢速度

安全红线 (绝对不要做)
================================================================================
✗ 不要在没有 RC 遥控器的情况下自主飞行
✗ 不要在人群附近飞行
✗ 不要在电池低于 30% 时继续飞行
✗ 不要在超出测距仪量程 (8m+) 的高度飞行
✗ 不要一开始就用仿真中的高速度 (6.9m/s)
✗ 不要在没有手动飞行验证前直接自主飞行
